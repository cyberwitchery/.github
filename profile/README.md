### cyberwitchery

we build tools for technical systems whose boxes need edges.

our work spans network automation, software assurance, programming languages, and developer tooling. across those domains, we build systems that connect existing tools, preserve their underlying models, and give their users more control.

#### what we build

##### infrastructure and network automation

* [alembic](https://github.com/cyberwitchery/alembic): connective tissue for network automation systems
* [netform](https://github.com/cyberwitchery/netform): a cautious intermediate representation and differ for network configurations
* rust clients and integrations for netbox, nautobot, infrahub, and adjacent infrastructure systems

##### software assurance

<!--* [divinate](https://github.com/cyberwitchery/sbom-diff): durable, inspectable evidence for security and compliance claims-->
* [sbom-diff](https://github.com/cyberwitchery/sbom-diff): structural comparison of software bills of materials
* [unsafe-budget](https://github.com/cyberwitchery/unsafe-budget): explicit budgets for unsafe Rust
* small security tools designed to compose with existing development workflows

##### programming systems

* [metacarp](https://github.com/cyberwitchery/metacarp): a self-hosted carp compiler and programming environment
* compiler, language-server, debugging, and interactive-programming infrastructure
* libraries and tools maintained together with the wider carp community

#### work with us

cyberwitchery is a small team of specialists working on developer experience, security architecture, network automation, programming languages, and technical due diligence.

we build our own products, maintain open-source infrastructure, and help organizations solve unusual technical problems.
